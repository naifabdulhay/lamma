# تحدّي اللمّة

لعبة أسئلة عائلية جماعية: شاشة واحدة (تلفاز أو لابتوب أو جوال المضيف) تعرض الأسئلة والباركود، وكل لاعب يمسح الباركود ويجيب من جواله. اللعب جولات من ١٠ أسئلة، والسؤال العاشر ذهبي بضعف النقاط، والإجابة الصحيحة الأسرع تأخذ نقاطًا أكثر.

## التشغيل

اللعبة كلها في ملف واحد: `index.html`. ارفعه على أي استضافة ثابتة، مثل Cloudflare Pages أو GitHub Pages، ثم:

1. افتح الرابط على الشاشة الكبيرة واختر «ابدأ لعبة جديدة».
2. يمسح الجميع الباركود ويكتبون أسماءهم.
3. اضغط «ابدأ اللعب».

كل الأجهزة تحتاج إنترنت؛ الربط بين الشاشة والجوالات يمر عبر خادم MQTT مجاني عام (EMQX ثم HiveMQ ثم Mosquitto تلقائيًا).

## المحتوى

أكثر من ١٠٦٠ سؤالًا مكتوبًا في `src/bank.js`، إضافة إلى أسئلة صور وأصوات تتولد تلقائيًا في `src/qgen.js`:
ثقافة عامة، علوم، جغرافيا، تاريخ، ما عاصمة، عملات، أول من، مخترعون وعلماء، دين، حكم فقهي، السيرة، المعارك الإسلامية، الأنبياء، الصحابة والتابعون، مطلع سورة، مفردة قرآنية، لغة عربية، أكمل البيت، من القائل، أمثال، English، روايات وكتب، ألغاز، القصة الناقصة، صح أم خطأ، خمّن من الرموز، الكلمة الدخيلة، رتّب، رياضيات، متتابعات، الكلمة المبعثرة، ما اسم هذا الجهاز، الجزء المظلل في الخريطة، أعلام الدول، معالم سعودية، اكتشف المختلف، الفرق بين الصورتين، القطعة الناقصة، ذاكرة الصورة، لون الكلمة، عُدّ بسرعة، كم صفارة، أذن ذهبية، تسلسل الألوان، رد الفعل.

## التعديل

- لإضافة أسئلة: عدّل `src/bank.js` (كل سطر: `السؤال|الصحيح|خطأ|خطأ|خطأ`).
- بعد أي تعديل: `npm install` ثم `npm run build` لإعادة توليد `index.html`.
- `npm run check` يولّد آلاف الأسئلة ويتحقق من سلامتها.
- للاختبار المحلي: `node test/broker.mjs . 8899` ثم افتح `http://localhost:8899/?broker=ws://localhost:8899/mqtt`.
